# 代码审查助手

> 专业的代码审查与质量评估提示词

## 功能说明

这是一个专业的代码审查助手 Prompt，帮助团队进行系统化的代码审查，覆盖代码质量、安全性、性能、可维护性等多个维度。

## 适用场景

- Pull Request 代码审查
- 代码合并前质量评估
- 代码重构前的现状分析
- 新人代码评审

## 审查维度

| 维度 | 说明 | 优先级 |
|------|------|--------|
| 代码正确性 | 逻辑是否正确，边界条件处理 | P0 |
| 安全性 | 潜在的安全漏洞、注入风险 | P0 |
| 代码风格 | 符合项目编码规范 | P1 |
| 性能 | 时间和空间复杂度 | P1 |
| 可维护性 | 代码结构、命名、可读性 | P1 |
| 测试覆盖 | 是否有充分的测试用例 | P2 |

## 审查输出模板

```markdown
## 代码审查报告

### 基本信息
- 审查人：[审查者]
- 审查时间：[日期]
- 代码变更：[文件列表]

### 总体评价
[总体评价]

### 问题清单

#### 🔴 严重问题
| 文件 | 问题 | 建议 |
|------|------|------|
| xxx | 问题描述 | 修复建议 |

#### 🟡 建议改进
| 文件 | 问题 | 建议 |
|------|------|------|
| xxx | 问题描述 | 改进建议 |

#### 🟢 最佳实践
| 文件 | 实践 | 说明 |
|------|------|------|
| xxx | 实践描述 | 说明 |

### 审查结论
- [ ] 通过审查
- [ ] 需要修改后重审
- [ ] 阻塞问题需修复
```

## 使用方式

### 基本用法

粘贴以下格式的代码信息：

```markdown
请审查以下代码变更：

【代码变更描述】
[简要说明本次变更的内容和目的]

【代码语言】
[如：Python/JavaScript/Go 等]

【代码内容】
[paste code here]
```

### 高级用法

提供更多上下文以获得更准确的审查建议：

```markdown
请审查以下代码变更：

【代码变更描述】
[简要说明本次变更的内容和目的]

【代码语言】
[如：Python/JavaScript/Go 等]

【所属模块】
[如：用户模块、订单模块等]

【相关依赖】
[相关的模块或服务]

【性能要求】
[如有特殊的性能要求]

【代码内容】
[paste code here]
```

## 审查原则

1. **建设性反馈**：指出问题的同时提供解决方案
2. **区分优先级**：明确区分必须修复和建议改进
3. **关注业务**：不仅看代码，也要理解业务逻辑
4. **一致性**：遵循项目既有的编码规范
