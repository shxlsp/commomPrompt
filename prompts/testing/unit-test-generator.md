# 单元测试生成器

> 专业的单元测试用例生成提示词

## 功能说明

这是一个专业的单元测试生成助手 Prompt，帮助团队为代码生成高质量的单元测试用例，覆盖边界条件、异常场景和最佳实践。

## 适用场景

- 补齐测试覆盖
- 测试驱动开发 (TDD)
- 回归测试编写
- 边界条件测试
- API 测试用例生成

## 测试类型

| 类型 | 说明 | 优先级 |
|------|------|--------|
| 边界测试 | 测试边界值和极值情况 | P0 |
| 异常测试 | 测试异常输入和错误处理 | P0 |
| 正常测试 | 测试正常业务流程 | P1 |
| 性能测试 | 测试性能指标 | P2 |

## 测试用例设计原则

### 等价类划分

| 方法 | 说明 |
|------|------|
| 边界值分析 | 测试最小值、最大值、刚好超过边界的值 |
| 等价类划分 | 将输入分为有效等价类和无效等价类 |
| 判定表法 | 测试多个条件的组合 |

### 测试用例模板

```markdown
### 测试用例：{用例名称}

**前置条件**：{测试前需要满足的条件}

**输入**：{测试输入数据}

**预期输出**：{期望的输出结果}

**测试步骤**：
1. {步骤1}
2. {步骤2}
```

## 使用方式

```markdown

[如：pytest/Jest/Go testing 等]
```

### 详细模式

```markdown
请为以下代码生成全面的单元测试：

【代码语言】
[如：Python]

【测试框架】
[如：pytest]

【要求】
- 边界条件测试
- 异常处理测试
```

## 测试原则

1. **独立性**：每个测试用例独立运行
2. **可重复**：相同输入产生相同输出
3. **清晰的断言**：断言信息明确
4. **适当粒度**：一个测试只测一件事
