# 代码重构助手

> 专业的代码重构分析与实施提示词

## 功能说明

这是一个专业的代码重构助手 Prompt，帮助团队分析代码问题、制定重构计划、实施重构方案，同时保持功能不变并提升代码质量。

## 适用场景

- 遗留代码优化
- 技术债务清理
- 代码质量提升
- 架构调整前的准备
- 性能优化重构

## 重构维度

| 维度 | 说明 | 优先级 |
|------|------|--------|
| 可读性 | 命名、注释、代码结构 | P0 |
| 可维护性 | 模块解耦、依赖管理 | P0 |
| 性能优化 | 算法优化、资源使用 | P1 |
| 测试覆盖 | 确保重构不破坏功能 | P1 |
| 渐进式 | 支持小步增量重构 | P1 |

## 识别代码异味

| 类型 | 描述 | 重构手法 |
|------|------|----------|
| 重复代码 | 相同或相似的代码片段 | 提取函数/类 |
| 过长函数 | 函数行数过多 | 拆分函数 |
| 过大类 | 类职责过多 | 提取类 |
| 参数过多 | 函数参数超过3个 | 参数对象化 |
| 过深嵌套 | 嵌套层级过深 | 提取函数/卫语句 |
| 霰弹式修改 | 修改需要改多个地方 | 搬移函数/合并 |

## 重构原则

1. **保持功能不变**：重构不改变外部行为
2. **小步增量**：每次只做一件事
3. **持续测试**：每步重构后运行测试
4. **可回滚**：确保可以恢复到之前状态
