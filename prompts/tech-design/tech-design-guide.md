# 技术方案设计助手

> 专业的技术方案文档生成提示词

## 功能说明

这是一个专业的技术方案设计助手 Prompt，帮助团队系统化地分析和设计技术方案，覆盖需求分析、架构设计、技术选型、风险评估等维度。

## 适用场景

- 新项目技术方案设计
- 系统重构方案设计
- 技术选型评估
- 架构优化分析
- 技术评审准备

## 设计维度

| 维度 | 说明 | 优先级 |
|------|------|--------|
| 需求分析 | 业务需求和技术需求 | P0 |
| 架构设计 | 整体架构和模块设计 | P0 |
| 技术选型 | 技术栈选择和对比 | P1 |
| 风险评估 | 技术风险和应对策略 | P1 |
| 实施计划 | 实施步骤和时间规划 | P1 |

## 技术方案结构

```
技术方案文档
├── 概述                    # 背景、目标、范围
├── 需求分析               # 业务需求、功能需求
├── 架构设计               # 整体架构、模块设计
├── 技术选型               # 技术栈对比、选型理由
├── 详细设计               # 核心流程、数据模型
├── 接口设计               # API 设计、数据格式
├── 安全设计               # 认证、授权、数据安全
├── 性能设计               # 性能指标、缓存策略
├── 部署方案               # 部署架构、运维策略
├── 风险评估               # 风险识别、应对策略
└── 实施计划               # 里程碑、排期
```

## 使用方式

### 基本用法

```markdown
请设计以下技术方案：

【项目名称】
[项目名称]

【业务背景】
[简要描述业务背景]

【核心需求】
[描述核心功能需求]

【约束条件】
[技术约束、时间约束等]
```

### 详细模式

```markdown
请设计详细的技术方案：

【项目名称】
[项目名称]

【业务背景】
[业务背景描述]

【功能需求】
1. [需求1]
2. [需求2]

【非功能需求】
- 性能要求：[描述]
- 可用性要求：[描述]
- 安全性要求：[描述]

【技术约束】
- 技术栈限制：[约束]
- 预算限制：[约束]
- 时间限制：[约束]

【参考系统】
[相关系统的描述]
```

## 方案输出模板

```markdown
## 技术方案

### 概述

#### 背景
[项目背景]

#### 目标
- 目标1
- 目标2

#### 范围
[方案覆盖范围]

### 需求分析

#### 功能需求
| 需求ID | 需求描述 | 优先级 |
|--------|----------|--------|
| REQ-01 | 描述 | P0 |

#### 非功能需求
| 指标 | 要求 |
|------|------|
| 性能 | QPS ≥ 1000 |
| 可用性 | 99.9% |
```
