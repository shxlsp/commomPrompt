# 项目文档生成器

> AI 软件工程项目学习文档生成指南

## 功能说明

这是一个专业的技术文档工程师 Prompt，用于为任意软件工程项目生成一套完整的、分层的学习文档体系，帮助研发人员快速了解项目并指导开发工作。

## 适用场景

- 为新项目生成完整的文档体系
- 为现有项目补充缺失的文档
- 增量更新项目文档
- 生成技术手册、API 文档、架构文档

## 输出文档结构

```
docs/
├── 01_快速概览.md          # 快速概览 + 核心入门（10分钟阅读）
├── 手册/
│   ├── README.md           # 手册总索引
│   ├── 架构/               # 架构文档
│   ├── 模块/               # 模块详解
│   ├── 指南/               # 实用指南
│   └── 参考/               # 参考资料
```

## 核心特性

| 特性 | 说明 |
|------|------|
| 三层文档结构 | 快速概览 → 核心入门 → 深度手册 |
| 语言无关 | 使用占位符适配任意编程语言 |
| 自适应结构 | 根据项目规模自动调整文档复杂度 |
| 代码可运行 | 所有示例代码完整可执行 |

## 使用方式

在 AI 对话中直接发送 `project-docs-generator_prompt.md` 文件内容，或粘贴以下格式的项目信息：

```markdown
项目名称：{项目名}
编程语言：{语言及版本}
项目类型：{前端/后端/全栈/工具/框架/SDK}
技术栈：{核心框架和依赖}
项目描述：{一句话描述}
```

## 示例

输入项目信息后，AI 将生成：
- 项目基本信息和技术栈全景
- 架构简图（ASCII/Mermaid）
- 快速导航索引
- 环境准备与安装步骤
- 可运行代码示例
- 模块导航表和常见问题
